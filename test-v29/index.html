Historique

Chaque résultat reste modifiable en le supprimant puis en le ressaisissant.

Synchronisation Firebase

Les résultats de chaque chien sont enregistrés dans un espace privé lié à votre compte Google. La synchronisation Google Drive précédente est désactivée dans cette version de test.

Sauvegarde et transfert

Conservez également une sauvegarde JSON indépendante de Google Drive.

Mode d'emploi

  1. Renseignez le nom du chien dans « Progression ».
  2. Dans « Ajouter », saisissez une ligne pour chacun des quatre exercices de chaque concours.
  3. Une validation Classique est comptée lorsque les quatre exercices sont qualifiés pour le même chien, la même date, le même concours et le même niveau.
  4. Une validation Variable nécessite trois qualifications dans chacun des quatre exercices du même niveau, y compris celles de concours Classiques. Les compteurs continuent au-delà de trois.
  5. « Progression » affiche les validations répétées et les qualifications encore nécessaires pour la prochaine Variable.
  6. Connectez le même compte Google sur vos appareils. Chaque propriétaire voit uniquement ses chiens. Conservez un export JSON de sécurité.
  7. Pour demander à ChatGPT d'analyser un PDF de résultats, transmettez-lui le PDF et votre export CSV, puis vérifiez les résultats proposés avant de les saisir dans l'application. L’import PDF, images et texte est disponible dans Ajouter.
