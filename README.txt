Nosework Tracker USCSS — Prototype PWA v1

Pour installer sur Android : publier le contenu de ce dossier sur un hébergement HTTPS (ex. GitHub Pages), ouvrir l'URL dans Chrome Android, puis choisir « Installer l'application » ou « Ajouter à l'écran d'accueil ».

Ne pas ouvrir index.html directement depuis un gestionnaire de fichiers : l'installation PWA et le service worker exigent HTTPS ou localhost.

Fonctionnalités : saisie manuelle, progression Classique/Variable, historique, sauvegarde JSON, export CSV, fonctionnement hors ligne après première visite.

Non inclus dans cette version : synchronisation automatique Google Drive, authentification Google, import PDF, appel à ChatGPT, import automatique du fichier Excel. L'export JSON peut être stocké manuellement dans Google Drive.

Attention : stockage local au navigateur/appareil. Faire des sauvegardes JSON régulières avant suppression des données du navigateur ou changement de téléphone.
